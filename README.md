Twitter Ads: Billing Model A/B Test AnalysisProject Overview
This project evaluates a new impression-based billing model designed to solve "overspending" issues caused by delayed click reporting in the traditional click-based model.The ExperimentControl Group: Click-based billing.Treatment Group: Impression-based billing.Duration: 1 week.Key FindingsReduction in Overspend: The new model reduced average overspend by 7.71 percentage points (from 25.32% to 17.61%).Statistical Significance: The improvement was confirmed with a T-test ($p \approx 0.00002$).Segment Performance: * Large Companies: Improved by 9.03%.Small Companies: Improved by 9.96%.Medium Companies: Saw a slight increase in overspending (+0.58%), suggesting a need for further optimization for this segment.Technologies UsedPython: For data cleaning and manipulation.Pandas: For exploratory data analysis.Scipy (Stats): For T-tests, ANOVA, and Levene’s tests to ensure statistical rigor.
